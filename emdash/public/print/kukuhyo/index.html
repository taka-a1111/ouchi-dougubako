覚える順番つき九九表（A4・無料）

学校で習うことが多い順（5・2・3・4の段 → 6・7・8・9の段 → 1の段）に並べて色分けした九九表と、81個の唱え方の2枚セットです。机の前やトイレにはって、1段ずつ覚えるのに使えます。

Instagramの中では保存・印刷がうまくいかないことがあります いま開いているのはInstagramの中のブラウザです。PDFの保存や印刷は、ChromeやSafariで開き直すと確実です。
  1. 右上の「︙」または「…」を押す
  2. 「ブラウザで開く」（「Chromeで開く」「Safariで開く」）を選ぶ
Chromeで開く

コピーしました。ChromeやSafariのアドレス欄に貼り付けて開いてください。

PDFを開く（A4・2枚）

開いたPDFから、保存・印刷ができます。プリンターがない場合は、コンビニのネットプリントでも印刷できます。1枚目だけ印刷して、はっておくのもおすすめです。

1枚目：覚える順番つき九九表
2枚目：九九の唱え方（覚える順）
使い方
  • 1枚目を見ながら、上の段から1つずつ覚える
  • 2枚目で声に出して唱える。「上がり」「下がり」「バラバラ」の順にチェック
  • 6〜9の段は、1日1つの段にしぼって短い時間で何回も

習う順番は教科書によって少し違います。唱え方も地域や学校で少し違うことがあります。学校で習った順番・言い方を優先してください。

覚えたら、スマホでタイムアタック

段ごと・バラバラ・苦手だけの3つのモードで、九九の速さをはかれます。同じ問題をA4のプリントにもできます。
